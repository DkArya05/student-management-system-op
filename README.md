Student Management System

Project Overview

The Student Management System is a full-stack web application planned for managing student information and academic records in a centralized system.

Objectives

- Manage student records.
- Organize departments, courses, and enrollments.
- Record attendance and assessment marks.
- Provide authenticated access according to user roles.
- Reduce manual record-management work.

Technology Stack

- Frontend: React and Vite
- Backend: Node.js and Express.js
- Database: MongoDB
- Version Control: Git and GitHub
