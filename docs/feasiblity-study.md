Feasibility Study

Project Title

Student Management System — Full Stack Web Application

1. Technical Feasibility

The project is technically feasible because it uses commonly available web development technologies. React with Vite will be used to develop the frontend, Node.js and Express.js will handle backend operations, and MongoDB will store student and academic records.

The team can use Visual Studio Code for development and GitHub for version control. AI-assisted coding tools may help generate and review code, but all generated code must be checked and tested by the team.

2. Economic Feasibility

The project can be developed at a low cost because the selected technologies and development tools are available free of charge for this academic project. A personal computer and an internet connection will be required. Hosting or other optional services may involve additional costs.

3. Operational Feasibility

The proposed system will provide a user-friendly interface for authorized college users. It aims to simplify student record management, attendance tracking, enrollment management, and marks recording. Basic user guidance will help users understand the system.

4. Schedule Feasibility

The project is planned for development over ten days by a team of four BCA students. The team will divide responsibilities among system analysis, backend development, frontend development, testing, and integration.

The schedule is achievable only if the team prioritizes essential features, reviews progress daily, and resolves issues promptly. Advanced features may be postponed if time is limited.

5. Security and Data Feasibility

The system will use authentication and role-based access control to restrict access to authorized functions. Passwords should be stored using secure hashing, and inputs must be validated. MongoDB will store the application's records.

The team must test access permissions, data validation, and error handling before considering the system ready for demonstration.
